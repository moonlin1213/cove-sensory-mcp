# Cove Sensory MCP

Cove Sensory MCP——给纯文本 LLM 一双眼睛和耳朵

A privacy-safe, cross-platform local stdio MCP package for Python 3.11 and later.

## Development

Install the development dependencies with `uv sync --group dev`, then verify the
package version with:

```console
uv run python -m cove_sensory_mcp --version
```
